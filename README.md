# Marina Tkachenko — Product Designer portfolio

A bilingual (RU/EN) static site built with HTML, CSS and vanilla JavaScript.

## Run locally

```
python3 -m http.server
```

Then open http://localhost:8000/.

## Structure

- `index.html`, `projects.html`, `cases/`: pages; `css/`, `js/`, `data/`: styles, scripts and content.
- `images/`, `assets/`, `fonts/`, `files/`: media, fonts and resume PDFs.
